Score the candidate's screening interview on four competencies. Each score
is an integer 0-100. For each, give 1-3 evidence_quotes (word for word from the
candidate's lines) and a 1-2 sentence rationale.

Rubric:

1. role_knowledge: hands-on knowledge of this job's core work (see the job's
   must-have skills and responsibilities), as shown in the candidate's answers.
   100 = specific, correct detail about building exactly this kind of work.
   70  = relevant real experience, described with some specifics.
   40  = general or second-hand statements, few specifics.
   0   = nothing relevant said.

2. problem_solving: how the candidate describes diagnosing and solving a real
   problem (cause, steps, outcome).
   100 = clear cause, method and result. 50 = partial story. 0 = none given.

3. communication: clarity and structure of the answers for a spoken call
   (answers the question asked, easy to follow, concise).
   100 = consistently clear. 50 = understandable but rambling or vague. 0 = unclear.

4. motivation: genuine interest in this role and alignment on practicalities
   (interest, availability, location/relocation, notice period).
   100 = clearly interested and aligned. 50 = lukewarm or some friction. 0 = not interested.

Also list concrete concerns for the hiring team (empty if none) and write a
2-3 sentence summary.
